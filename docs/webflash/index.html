RRp38KLine — flash a new board

ESP32-C6 K-line diagnostic interface for the Range Rover P38A. This page flashes the latest firmware from master onto a board straight from your browser, with no toolchain. Works in Chrome or Edge on desktop (Web Serial), over a USB cable.

Know your EKA code before connecting to the car. Malformed traffic to the P38 BeCM is a documented cause of immobiliser lockout. Start with the passive build: it cannot transmit at all.

Before you start
  1. Plug the ESP32-C6 into this computer via its USB port. If no port appears, hold BOOT while plugging in.
  2. Click a Flash button and pick the board's serial port.
  3. Choose Erase device when offered. A board flashed over earlier firmware has run with its WiFi access point reported up but silent on air; a clean install avoids that.
  4. After flashing, join the board's WiFi RRp38-KLine (password rrp38kline) and open http://192.168.4.1/. Change that password on the WiFi tab.

Every update after this goes over the air from the board's OTA Update tab, including switching between the passive and TX builds.

Firmware built automatically from SEspe/RRp38KLineInterface master via GitHub Actions.
